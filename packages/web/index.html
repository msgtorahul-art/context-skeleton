FREQUENTLY ASKED QUESTIONS

Everything You Need to Know

Does ContextSkeleton send my code to any server?

No. ContextSkeleton runs 100% locally on your machine via client-side Wasm and local CLI. Zero bytes of your source code ever leave your environment.

How does AST folding prevent context rot?

By removing deep function bodies while keeping function signatures, types, and JSDoc comments, the AI agent understands your entire architectural skeleton without being overwhelmed by implementation details.

How do I connect ContextSkeleton to Cursor or Claude Code?

Simply add our stdio MCP server to your `claude_desktop_config.json` or `.cursorrules`. It exposes tools that allow the AI to query repository skeletons automatically.
