Security Policy

Last Updated: August 2026

1. Air-Gapped Local Architecture

ContextSkeleton requires zero external network connections to prune code syntax. Secret API keys, credentials, and proprietary code logic stay strictly inside your workstation environment.

2. Secret & PII Auto-Masking

Enterprise and Pro versions automatically scan AST nodes for high-entropy strings, passwords, and private tokens, replacing them with `[SECRET_MASKED]` before prompt assembly.

3. Vulnerability Reporting

Please report any security concerns directly to security@contextskeleton.com.
