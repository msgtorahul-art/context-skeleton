Security & Compliance Policy

Published by FunctionApp (functionapp.in)

1. Local Air-Gapped Code Processing

Security is fundamental to ContextSkeleton. All code parsing, structural folding, and token estimation execute locally within your local Node.js process. At no point does the CLI or MCP server make outbound HTTP connections or upload source code snippets to external servers.

2. Secret & API Key Protection

Secrets inside folded function bodies are not included in the output skeleton; secrets in top-level constants or module scope are not currently filtered and should not be hardcoded in source code.

3. Reporting Security Vulnerabilities

If you discover a security vulnerability in ContextSkeleton or FunctionApp products, please report it via our platform at functionapp.in or create a GitHub issue on our repository.
