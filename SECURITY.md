# Security Policy

## Supported Versions

Only the latest release version of ContextSkeleton is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for security vulnerabilities, as this exposes unpatched flaws to the public.

Instead, please submit security vulnerability reports privately using GitHub's Private Vulnerability Advisory feature:

👉 **[Submit a Private Security Advisory](https://github.com/msgtorahul-art/context-skeleton/security/advisories/new)**

Alternatively, you may contact the maintainers directly via email at `contact@functionapp.in`.

### Response & Handling Timeline
- **Acknowledgement**: Within 24 hours of submission.
- **Triage & Assessment**: Within 48 hours.
- **Fix & Disclosure Release**: Coordinated fix and security advisory release within 7 days.
